Features

Stop dragging files by hand.

Everything you need to automate.

Auto-Flow rules

If it matches, it happens. Combine conditions — file type, age, size, name, screenshot — with AND/OR, then pick an action: move, rename, archive, trash, or run a script. Runs immediately, hourly, or daily. No clicking, ever.

Smart Sanitize

One-tap scan for junk piling up on your Mac — old downloads, duplicate screenshots, forgotten installers. See exactly what's about to go before it's gone. Nothing deletes without your say.

Runs 100% on-device

No cloud, no account, no upload. iOrganize watches your folders locally and never sends a single file anywhere. Your Downloads folder stays exactly as private as it always was.

Daily screenshot wipe

Screenshots pile up fast. Set it once: "Delete screenshots older than 1 day" runs every morning while you sleep. Reclaim space automatically, wake up to a clean Mac.

How It Works

Three steps. Zero maintenance.

01

Pick a folder & condition

Point a rule at Downloads, Desktop, or anywhere. Set a condition — "File type is .dmg", "Older than 30 days", "Is a screenshot" — combine several with AND/OR.

02

Choose what happens

Move to a folder, rename with a pattern, archive to zip, move to Trash, delete permanently, open with an app, or run a custom script.
