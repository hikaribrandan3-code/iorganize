# iOrganize

A macOS utility for organizing files with folder rules and cleanup scans. The native SwiftUI app keeps file processing on the Mac and does not require an account or license.

## macOS source

The complete native app source and build instructions are in [`macos-source/`](macos-source/README.md). The project uses Swift 6.1, SwiftUI, and targets macOS 14 or later.

## Website

The repository root also contains the product website. It describes the app and links to the source. iOrganize is free and open source under the MIT License.

## Current distribution status

The source is available here. No packaged app download is published yet. The older ZIP was removed because it contains the previous paid build. Use the source build instructions above until a fresh free build is available.
